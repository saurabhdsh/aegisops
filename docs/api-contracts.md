# API contracts

Base path: `/api/v1`. Errors use one shape:

```json
{
  "error": {
    "code": "not_found",
    "message": "Incident not found",
    "correlation_id": "cor_...",
    "details": {}
  }
}
```

| Status | Code |
| --- | --- |
| 401 | `unauthorized` |
| 403 | `forbidden` |
| 404 | `not_found` |
| 409 | `conflict` |
| 422 | `validation_error` |
| 429 | `rate_limited` |
| 501 | `not_implemented` |
| 502 | `integration_error` |
| 500 | `internal_error` |

Operational routes require `Authorization: Bearer` or the `aegisops_session` cookie. Cookie mutations also require `X-CSRF-Token` from the login response.

## Implemented

| Method | Path | Behavior |
| --- | --- | --- |
| GET | `/health`, `/ready`, `/api/v1/health` | Process and database status. No auth. |
| POST | `/api/v1/auth/login` | Issues a signed token and stores only its hash. |
| POST | `/api/v1/auth/logout` | Revokes the server session. |
| GET | `/api/v1/auth/me` | Current user, tenant, and roles. |
| GET | `/api/v1/incidents` | Tenant-scoped page. When a ServiceNow connection is saved, refreshes up to 50 incidents first. A failed refresh is 502 and does not substitute fixtures. |
| GET | `/api/v1/incidents/{id}` | 404 when the id is missing or belongs to another tenant. |
| GET | `/api/v1/incidents/{id}/analysis` | Read-only rank of CPU and memory. Uses Dynatrace when a connection is saved and the entity is not a `DEMO-` host. Otherwise uses stored samples. Does not open a workflow or call a model. |
| GET | `/api/v1/incidents/{id}/evidence` | Stored evidence only. |
| POST | `/api/v1/incidents/{id}/investigate` | Opens or returns the incident workflow and runs until approval or a terminal state. |
| GET | `/api/v1/workflows` and `/{id}` | Persisted workflows. |
| GET | `/api/v1/workflows/{id}/steps` | Transition steps. |
| GET | `/api/v1/workflows/{id}/events` | Outbox after a sequence. |
| GET | `/api/v1/workflows/{id}/stream` | SSE replay. `Last-Event-ID` is the last sequence. |
| POST | `/api/v1/workflows/{id}/cancel` | Cancels, or records `cancel_requested` when an external action may be running. |
| GET | `/api/v1/agents` | Catalog. Agents run only inside the engine. |
| GET | `/api/v1/agent-executions/{id}` | Stored executions. Empty until agents run. |
| GET | `/api/v1/approvals` and decision posts | Real decisions against stored requests. |
| GET | `/api/v1/runbooks` | Stored definitions. |
| GET | `/api/v1/integrations` | Stored rows. No secrets. |
| POST | `/api/v1/integrations/servicenow/test` | Health check. Uses a saved connection when one is complete. Otherwise `SIMULATOR` uses fixtures. |
| POST | `/api/v1/integrations/dynatrace/test` | Health check. Uses a saved connection when one is complete. Otherwise `SIMULATOR` uses fixtures. |
| GET | `/api/v1/settings/connections` | URLs, auth mode, and whether a secret is stored. Never the secret. |
| PUT | `/api/v1/settings/connections/servicenow` | Saves the ServiceNow connection. A blank secret keeps the stored secret. |
| PUT | `/api/v1/settings/connections/dynatrace` | Saves the Dynatrace connection. A blank token keeps the stored token. |
| PUT | `/api/v1/settings/connections/openai` | Saves OpenAI or Azure OpenAI. A blank key keeps the stored key. |
| POST | `/api/v1/settings/connections/{kind}/test` | Calls the saved connection. `kind` is `servicenow`, `dynatrace`, or `openai`. Failure is 502. |
| POST | `/api/v1/simulator/scenarios/compute-incident` | `SIMULATOR` only. Loads fixture `INC0012345`. |
| POST | `/api/v1/simulator/scenarios/disk-capacity` | `SIMULATOR` only. Loads the disk fixture. |
| GET | `/api/v1/capacity/assets` | Configuration items for the tenant. |
| GET | `/api/v1/capacity/forecasts` | Linear slopes. Stored disk observations until Dynatrace is saved, then live disk points for non-demo entities. A failed live read is 502. |
| GET | `/api/v1/telemetry/metrics` | Stored observations. |
| GET | `/api/v1/audit` | Append-only events for the tenant. |
| GET | `/api/v1/operations/controls` | Emergency stop and autonomy level. |
| POST | `/api/v1/operations/emergency-stop` | Admin only. |
| POST | `/api/v1/operations/autonomy` | Rejects L4 when the flag is off. |
| POST | `/api/v1/webhooks/dynatrace` | 401 unless the saved webhook secret, or `DYNATRACE_WEBHOOK_SECRET` when none is saved, matches `X-Aegis-Webhook-Token`. A match stores one event. A repeated `event_id` returns that row. |
| POST | `/api/v1/webhooks/servicenow` | Same, with the saved ServiceNow webhook secret or `SERVICENOW_WEBHOOK_SECRET`. |

SSE events look like:

```json
{
  "event_id": "obx_...",
  "workflow_id": "wf_...",
  "sequence": 1,
  "timestamp": "2026-11-07T01:00:00+00:00",
  "type": "workflow.received",
  "payload": {"state": "RECEIVED", "kind": "incident"}
}
```

OpenAPI is generated by FastAPI at `/openapi.json`. A typed TypeScript client waits for the web application.
